# 调料使用速查表

## 一、调料使用表

| 调料 | 核心作用 | 最适合的食物 | 最佳时机 | 备注 |
|---|---|---|---|---|
| 新鲜蒜 | 爆香、蒜粒口感、锅气 | 炒菜、蒜蓉菜、蒜香油 | 下锅爆香时 | 香气最强，适合中式爆炒。 |
| 蒜粉 | 均匀蒜味、干调味、控盐灵活 | 煎蛋、煎肉、腌料、汤、酱、水煮菜、汤面 | 腌制时、做汤时、出锅前少量补味 | 适合需要蒜味但不想切蒜；无油浸蒜时可与橄榄油现调替代。 |
| 洋葱粉 | 甜味底味、鲜味补充 | 煎蛋、煎肉、炖菜、汤面、腌料 | 和蒜粉/油脂+蒜香基底同步加入 | 和蒜粉搭配能让味道更圆润，是 house seasoning 的核心底味。 |
| 蒜粉+洋葱粉混合罐 | 万能鲜味底味模块 | 水油焖菜、煎蛋、腌肉、汤、拌面 | 料汁调配时或出锅前少量加 | 比单纯蒜粉层次更好，可独立控制盐和欧芹，灵活度高于欧芹大蒜盐。 |
| 油浸蒜 | 蒜香底味、蒜粒口感、天然蒜油 | 水油焖菜、腌肉、炖菜、汤面 | 作为油脂+蒜香基底的升级选项，连油带蒜使用 | 自制鲜蒜浸油有肉毒杆菌风险，不能常温保存；冷藏短期使用或分装冷冻。 |
| 欧芹大蒜盐 | 直接提味、带咸味的复合调料 | 煎蛋、煎面包、烤土豆、汤面、清汤面、番茄汤面 | 出锅前或边煎边撒 | 和蒜粉场景相近，但更适合少量直接撒，控盐灵活性低于分开用。 |
| 欧芹碎 | 清香点缀、表面增香 | 煎蛋、土豆、肉类、汤面、沙拉 | 出锅前撒 | 万能度最高，几乎都能搭一点，建议单独放按需使用。 |
| 百里香 | 炖煮融合、汤底提香 | 番茄汤面、炖鸡胸、炖牛肉、蘑菇菜 | 炖煮中途放 | 比迷迭香柔和，最适合汤和炖菜。 |
| 迷迭香 | 烤肉、腌肉、烤土豆 | 烤鸡、烤羊排、烤猪排、烤土豆 | 腌制时或烤制前 | 碎的更适合腌肉，整枝更适合烤制。 |
| 混合香草盐 | 快速复合调味 | 肉类、薯条、烤蔬菜 | 腌制或出锅后撒 | 偏快捷调味，适合很多咸味菜。 |
| 芹菜盐 | 清爽辛香、冷菜提味 | 鸡蛋、炸鱼薯条、热狗、番茄类 | 出锅后撒 | 用途较窄，但在西式快餐里很常见。 |
| 烟熏红椒粉 | 烟熏感、颜色、轻微甜香 | 烤鸡、土豆、炖豆、炖菜 | 腌制前或少量点缀 | 更适合增加风味层次，不建议久炒。 |
| 贵州蘸水 | 辣鲜复合、微辣提味 | 水油焖菜、凉拌菜、火锅蘸料、烧烤 | 加入料汁中或出锅前少量加 | 钠含量极高，用量要少，搭配时大幅减少酱油蚝油用量。 |

## 二、选择逻辑表

| 你想要什么 | 选什么最合适 |
|---|---|
| 爆炒香气 | 新鲜蒜 |
| 方便省事 | 蒜粉 |
| 鲜味更圆润、层次更好 | 蒜粉+洋葱粉混合 |
| 直接撒一点就能吃 | 欧芹大蒜盐 |
| 汤面提香 | 蒜粉、欧芹大蒜盐、百里香 |
| 煎蛋提味 | 欧芹大蒜盐、蒜粉 |
| 炖煮出层次 | 百里香 |
| 烤肉或腌肉 | 迷迭香 |
| 万能点缀 | 欧芹 |
| 微辣鲜香提味 | 贵州蘸水（少量） |
| 想控盐灵活 | 蒜粉+洋葱粉混合（盐和欧芹碎单独放） |
| 水油焖菜日常主力 | 蒜粉（+洋葱粉）+ 橄榄油现调 |
| 水油焖菜香气升级 | 油浸蒜作为底味，前提是能遵守冷藏/冷冻安全规则 |
| 有番茄时是否必须油浸蒜 | 不必须；番茄负责汤底和酸鲜，蒜味可用蒜粉、鲜蒜或油浸蒜任选 |

## 三、油浸蒜 vs 蒜粉+橄榄油现调

| 维度 | 油浸蒜 | 蒜粉+橄榄油现调 |
|---|---|---|
| 制作 | 需提前加热制作，一次做一小瓶 | 随用随调，10秒搞定，无储存压力 |
| 蒜香强度 | 蒜香更浓郁，接近现炒蒜香 | 蒜味稍柔和，但日常完全足够 |
| 口感 | 有蒜粒，吃得到蒜的质感 | 无颗粒，完全融入酱汁中 |
| 风味风格 | 更厚重、立体，适合想让蒜稍微当主角的菜 | 风味干净、均匀，更像“背景蒜味” |
| 保存 | 自制鲜蒜浸油需立即冷藏并按保守规则 4 天内用完；更久保存应分装冷冻；商业成品按标签保存 | 不存放，现调现用，无额外风险 |
| 便利性 | 需要提前规划和制作 | ✅ 日常更省事，适合懒人高频使用 |
| 控量灵活性 | 每次舀油和蒜，量略难精准控制 | ✅ 蒜粉、油、盐都能分开精细控制 |
| 营养成分 | 基于鲜蒜，保留部分接近鲜蒜的活性成分和营养 | 蒜粉在加工中已损失部分营养，更多当作风味来源 |
| 日常营养角度 | 对整体饮食营养贡献依然很小，可视为“有更好、没有也无所谓” | 同样贡献极小，和油浸蒜差异可以忽略，按口味和便利性选就行 |

> **建议**：蒜粉+橄榄油现调可以作为日常主力；油浸蒜只适合作为遵守冷藏/冷冻规则时的升级版。有番茄时不需要专门为了番茄使用油浸蒜，番茄负责汤底和酸鲜，油浸蒜只由口味需求和保存安全决定。

## 四、水油焖菜通用操作步骤

> **一句话公式**：先定基础调料，再选风味路线，最后小火盖焖并出锅微调。  
> 基础调料负责“稳定好吃”，风味路线负责“今天吃成什么味”。

### 4.1 基础用量

| 项目 | 建议量 |
|---|---|
| 蔬菜总量 | 个人一餐生重 250–350g |
| 橄榄油 | 总量约 10g；包括油浸蒜中的油和出锅追加油 |
| 蒜粉 / 鲜蒜 | 蒜粉 1/4–1/2 茶匙，或鲜蒜 1–2 瓣 |
| 无盐番茄丁 / 鲜番茄 | 60–100g，或鲜番茄 1/2–1 个 |
| 清水 | 0–3 汤匙 |
| 盐 / 欧芹大蒜盐 | 少量起步；使用生抽、蚝油、贵州蘸水时不叠加 |
| 黑胡椒 | 1/8–1/4 茶匙 |

### 4.2 基础调料：所有路线共用

| 模块 | 选择 | 默认量 | 作用 |
|---|---|---|---|
| 油脂 + 蒜香基底 | 橄榄油 + 蒜粉 / 橄榄油 + 鲜蒜 / 油浸蒜 | 总油约 10g | 提供香气、口感和脂溶风味 |
| 汤底基底 | 番茄 / 清水 | 番茄 60–100g；清水 0–3 汤匙 | 提供汁水，避免干锅 |
| 基础辛香 | 盐或欧芹大蒜盐 + 黑胡椒 | 盐少量；黑胡椒 1/8–1/4 茶匙 | 建立基础咸味和辛香层次 |

> **油浸蒜说明**：油浸蒜属于“油脂 + 蒜香基底”的升级选项，不是单独风味路线。使用时连油带蒜计入本餐总油量。

### 4.3 风味路线：在基础调料上调整

| 路线 | 怎么调整 | 适合场景 | 避免 |
|---|---|---|---|
| 地中海清淡风 | 优先用番茄；洋葱粉 1/8–1/4 茶匙建议默认加；欧芹碎、百里香或罗勒至少选一种；黑胡椒可取 1/4 茶匙 | 日常主力、想要清爽草本香 | 生抽、蚝油、贵州蘸水、香油 |
| 中式 / 中西结合风 | 在基础上加生抽或蚝油二选一，≤1 茶匙；黑胡椒取低值；番茄可少量保留；洋葱粉可保留 | 想要一点酱香和熟悉下饭感 | 额外盐、欧芹大蒜盐和酱油叠加 |
| 川贵微辣风 | 贵州蘸水 1/4–1/2 茶匙；生抽或蚝油二选一，≤1 茶匙；出锅可滴几滴香油 | 想吃微辣、糊辣香、口味更重时 | 欧芹碎、百里香、罗勒、黑胡椒、额外盐 |

> **控盐不是单独路线**：控盐是所有路线的执行规则。原则是“咸味来源只选一个”，少盐时用番茄、洋葱粉、黑胡椒和香草补味。

### 4.4 三种常用组合

| 组合 | 适合什么时候 | 调法 |
|---|---|---|
| 地中海日常版 | 最推荐的默认做法 | 橄榄油蒜香基底 + 番茄 + 洋葱粉 + 欧芹大蒜盐/少量盐 + 黑胡椒 + 百里香/欧芹碎 |
| 地中海无番茄简易版 | 没有番茄但仍想清淡 | 橄榄油蒜香基底 + 清水 + 洋葱粉 + 黑胡椒 + 欧芹大蒜盐/少量盐 + 百里香/欧芹碎 |
| 中式轻酱香版 | 想换口味但不重口 | 油脂蒜香基底 + 少量番茄/清水 + 生抽或蚝油二选一 + 黑胡椒少量 |

### 4.5 实际操作顺序

1. **切菜**：蔬菜切成大小接近的块或段。
2. **调基础调料**：选一种油脂蒜香基底，加番茄或清水，再加少量盐/欧芹大蒜盐和黑胡椒。
3. **接入风味路线**：按地中海、中式 / 中西结合或川贵微辣加入对应调料。
4. **入锅焖制**：蔬菜铺入锅中，酱底均匀淋在表面，小火盖焖。
5. **出锅微调**：淡了补一种咸味来源，干了补 1–2 汤匙水，香气不足再按路线补欧芹碎、生橄榄油或香油。

## 六、house seasoning / 自制万用调料

### 什么是 house seasoning
一套由自己配好的、什么菜都能用的"万用调味粉"。每家配方不同，强调是"我家这一款"，等同于 all-purpose seasoning（万能调味）。

### 推荐配方：蒜粉+洋葱粉万用底味罐
> **蒜粉 2份 + 洋葱粉 1份**，混匀装罐备用。  
> 盐和欧芹碎单独放，按需另加。

**优点**：比欧芹大蒜盐更灵活，咸度可自由控制，欧芹可加可不加。

### 拓展版（加入更多）：
> 蒜粉 2份 + 洋葱粉 1份 + 盐 2份 + 欧芹碎 1份  
> 可再加少量黑胡椒或烟熏红椒粉，增加辣味层次。

### 适合搭配的风格

| 想要什么风格 | 在底味罐基础上加 |
|---|---|
| 日常清淡 | 底味罐 + 盐 + 欧芹 |
| 微辣川贵风 | 底味罐 + 贵州蘸水 |
| 更传统川贵风 | 减少底味罐，多用鲜蒜 + 辣椒/花椒 |
| 西式草本风 | 底味罐 + 盐 + 百里香/欧芹 |

## 七、汤面是否适合欧芹大蒜盐

| 汤面类型 | 适合度 | 用法 |
|---|---|---|
| 清汤面 | 适合 | 少量出锅前撒，别放太多 |
| 番茄汤面 | 很适合 | 和番茄、百里香很搭 |
| 奶油面/黄油面 | 很适合 | 直接提香很好用 |
| 速食面 | 适合 | 可以当作补香补味的替代 |

## 九、自制欧芹大蒜盐配方

> 盐 3份 + 蒜粉 1份 + 干欧芹碎 1份，混匀装瓶即可。  
> 可根据口味调整蒜粉比例，喜欢蒜香重可提高到 1.5 份。

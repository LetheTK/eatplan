# 一周训练计划

## 训练总览

| 天 | 类型 | 晨间热身 | 正式训练 |
|----|------|---------|---------|
| 第1天 | 💪 力量 | 并入正式训练 | 力量训练A |
| 第2天 | 🚶 恢复 | 俯卧撑1组×12 + 深蹲20个，循环5组 | 散步 + 拉伸10分钟 |
| 第3天 | 🏃 跑步 | 同上 | 跑步5km |
| 第4天 | 💪 力量 | 并入正式训练 | 力量训练A |
| 第5天 | 🚶 恢复 | 同上 | 散步 + 拉伸10分钟 |
| 第6天 | 🏃 跑步 | 同上 | 跑步5km |
| 第7天 | 😴 休息 | 同上（轻量） | 无训练 |

> **灵活调整三原则（日期可变，规则不变）**
> - 💪 力量训练后隔1天再跑步
> - 🏃 两次跑步之间隔1天
> - 😴 每周保证1～2天完全休息


总结

|顺序         |间隔建议              |
|-----------|------------------|
|力量 → 有氧（同天）|10–30分钟，有氧控制在30分钟内|
|有氧 → 力量（同天）|不推荐，若必须至少间隔6小时    |
|分开训练（不同天）  |最理想，互不干扰          |

核心原则：以目标为导向。 以增肌为主 → 力量优先，有氧少而精；以减脂为主 → 两者都要，但先力量后有氧效果更佳。

## 💪 力量训练A（超级组交替版，约45分钟）

| 阶段 | 内容 | 时长/量 |
|------|------|--------|
| 热身 | 高抬腿、髋部绕环、肩部绕环 | 5分钟 |
| 第1轮 | 宽距俯卧撑×12 → 深蹲×20 → 休息 | 60～90秒休息 |
| 第2轮 | 窄距俯卧撑×12 → 深蹲×20 → 休息 | 60～90秒休息 |
| 第3轮 | 斜向俯卧撑×12 → 深蹲×20 → 休息 | 60～90秒休息 |
| 第4轮 | 常规俯卧撑×12 → 深蹲×20 → 休息 | 60～90秒休息 |
| 第5轮 | 自选/补强俯卧撑×12 → 深蹲×20 → 休息 | 60～90秒休息 |
| 核心1 | 平板支撑 × 3组 | 30～45秒/组，休息45秒 |
| 核心2 | 卷腹×15 × 3组 | 休息45秒 |
| 拉伸 | 股四头肌、髂胫束、胸肌、小腿 | 每个30秒，共5分钟 |

> **主体完成量：俯卧撑 60个 + 深蹲 100个**

---

## 🚶 恢复日内容

- 散步 20～30分钟
- 全身拉伸 10分钟（重点：股四头肌、髂胫束、胸肌、小腿）

---

## 📈 进阶信号

当以下情况出现，说明该升级难度：
- 深蹲5轮做完没有酸胀感
- 俯卧撑每组12个最后几个不费力
- 隔天完全没有延迟性酸痛

**升级方式：** 深蹲背书包负重（4瓶1.5L水 ≈ 6kg），俯卧撑每组加至15～20个
